# Keychron K2 ページデザイン

## 目的

`keyboards/keychronk2.html` は、Keychron K2 のキー配列をブラウザ上で可視化し、押下されたキーと対応するスイッチ情報を確認できるページである。本資料では、現行HTMLが担っている情報と操作を記録したうえで、操作状態とスイッチ情報を1画面で確認できるデザイン方針を定義する。

この設計を `keyboards/keychronk2.html` に反映し、白基調のキーボード表示と5つのカラーバリエーションを同じページで確認できる状態にする。

## Issue #140で確定した要件

### 表示対象とviewport

- 対象はPCとiPad横向き表示に限定する。スマートフォン表示は今回の設計・検証対象外とする。
- 対象viewportはPC `1280×800`、iPad横向き `1024×768` とする。
- 本体ワークスペースはどちらのviewportでも縦スクロールなしで成立させる。下部のカラーバリエーションを含むページ全体の縦スクロールは許可する。
- ヘッダー高は `56px` とし、本体ワークスペースは `calc(100vh - 56px)` で確保する。
- `1280×800` と `1024×768` では、本体ワークスペース内にキーボードとスイッチ情報を収め、下部の比較セクションはviewport外へ続ける。
- キーボード領域は上段の主領域として横幅いっぱいに置き、スイッチ情報領域はその下段に置く。キーボード領域は最小 `640px × 360px`、スイッチ情報領域は最小 `280px × 140px` を基準にする。
- ページ本体、キーボード領域、スイッチ情報領域のいずれにも縦スクロールバーを表示しない。

### 残す情報

- Keychron K2のキーボード配列。
- 押下中キーのハイライト。
- 押下キーに対応するスイッチ情報。
- スイッチ画像。

### 削除する表現

- `KEY INPUT VISUALIZER` のような、大文字だけで構成された見出し・ラベルは使用しない。
- `The keyboard, made visible.` や、機能説明に直接必要でないポエム調のコピーは使用しない。
- ヘッダー右上のボタン、CTA、装飾的な導線は置かない。

### ヘッダー

- ヘッダーに残す文字情報は `Portfolio Lab` と `Keychron K2` の2つだけとする。
- 既存の `Games`、`Keyboards`、`Experiments`、`Contact`、`Worksを見る`、`GitHub` の共通ナビは持ち込まない。
- `F1`、`ESC` などキーボード上のキー表記は機能上必要なため、大文字のみの削除対象には含めない。

### 構成

- 1画面にヘッダー、キーボード表示、スイッチ情報を収める。カラーバリエーションはページ下部へ分離する。
- ヒーロー、長い導入文、3つの観察ポイント、CTA、独立したフッターは削除する。
- キーボードを主領域に置き、スイッチ画像と詳細情報を同じ画面内のサブ領域に置く。
- コピーは機能名・キー名・スイッチ名・種別・荷重など、操作や状態の理解に必要な短い情報だけにする。

## 現行HTMLが表現していること

### ヘッダー

- 濃色の56pxヘッダーに `Portfolio Lab` と `Keychron K2` だけを置く。
- サイト共通ナビ、CTA、固定フッターは持たない。

### ページ見出し

- 本体見出しは `Keychron K2のキー配列` とする。
- 大文字のみの装飾的な見出し、ポエム調コピー、Homeリンクは置かない。

### キーボード可視化エリア

- Keychron K2 の配列を、6行のグリッドとして表現する。
- 32分割のグリッドを基準に、通常キー、Tab、Caps、Shift、Space、Enter などの幅を `grid-column` で調整する。
- `data-key` に表示名・識別名、`data-code` に `KeyboardEvent.code`、`data-combo` に修飾キーを含むコンビネーションを設定する。
- `sw-01` から `sw-17` のクラスで、キーに対応するスイッチカタログの分類を持つ。
- `device-key` はブラウザが直接入力を受け取れない本体専用キーを表し、破線で区別する。
- `macro-key` は `PgUp / Cmd+C`、`PgDn / Cmd+V` のような補助操作を表す。
- ページ内のJavaScriptがマウスオーバーとキーボード入力を監視し、該当キーへ `.active` を付与する。
- アクティブなキーは朱色の単色と小さな面の広がりで強調する。
- `light` や装飾キーなど、表示のみで入力を受け取れないキーについて注意書きを表示する。

### スイッチ情報エリア

- 押下キーの状態を、画像とテキストの2カラムで表示する。
- `switch-image` にスイッチ画像を表示し、読み込みに失敗した場合は `images/switch-placeholder.svg` に戻す。
- `switch-key-label` に押下キー、`switch-class-label` に `sw-XX` の分類を表示する。
- `switch-name-label` にスイッチ名、`switch-type-label` に種別と荷重を表示する。
- 初期状態は `未入力`、`未設定` とする。
- 外部画像URLを含むスイッチカタログはページ内のJavaScriptが保持する。

### 現行実装上の注意

- `<title>` は `Keychron K2 — キーボード入力` とし、スタイルとJavaScriptは `keychronk2.html` 内にまとめる。
- キー要素は `<button>` とし、クリック、マウスオーバー、キーボードフォーカス、`keydown` / `keyup` に対応する。
- 比較案は本番ページ下部に表示するが、比較案内のキーは操作対象から外し、メインキーボードの状態表示を優先する。
- `prefers-reduced-motion` では背景モーションとトランジションを抑制する。
- 対応キー入力では `event.preventDefault()` を実行し、ブラウザ既定の入力やショートカット動作を抑制する。

## 参考サイトから取り入れる方針

参考: [コクヨ 家具領域の広がり](https://www.kokuyo.com/about/business/furniture/)

- 主題は短く実務的な見出しで提示し、ポエム調の導入コピーは使わない。
- 明るいキャンバスと明るいキーボード展示面を使い、配列と状態を見やすくする。濃色はヘッダーや文字などの補助要素に限定する。
- 本番ページでは複数の縦長セクションや番号付きの章立てを採用せず、キーボードとスイッチ情報を上下2段に集約する。下部には色比較のための5案を同じ形式で置く。
- 装飾を増やすのではなく、見出し、余白、図版の大きさで視線を誘導する。

参考サイトのブランド表現を複製するのではなく、現在のページにある「入力を受けてキーを光らせる」体験を中心に、ポートフォリオ向けの展示表現へ翻訳する。

### KOKUYOらしさの取り込み方

- 参考ページの大きな見出し、余白、画像を主役にする面構成を、1画面のキーボード表示とスイッチ情報へ圧縮する。
- 白い紙面の上に白いキーボード展示面を置き、製品を見せる面と情報を読む面を明確に分ける。本体ページは上段のキーボードと下段の情報を同じviewport内に収め、色比較だけを下部へ続ける。
- 参考ページの動きの抑制という考え方だけを参照し、同じ文言やON / OFFボタンは再利用しない。専用ボタンを追加せず、`prefers-reduced-motion` と入力状態の変化量で実現する。
- 参考ページにある番号付きのストーリー構成はそのまま採用しない。その代わり、ページ下部の比較案に番号を付け、白いキーボードとスイッチ情報の構成へ同じ位置に一色だけを差し込んだカラーバリエーションを並べる。キー押下を起点にスイッチ情報が切り替わる状態は本体ページで表現する。
- KOKUYOの文章やブランド表現をコピーせず、Keychron K2のキー名・スイッチ名・種別・荷重という実用情報を、製品紹介のように編集して見せる。

### デザイン比較案

本体ページ下部に、以下の5案を同じ形式で縦に比較表示する。背景、カード、大半のキーキャップは白基調で統一し、案ごとにアクセント色をキー、番号、罫線、スイッチ表示へ限定的に配置する。

| 案 | アクセント色 | 淡色キー | 適用箇所 | 強調表現 |
| --- | --- | --- | --- | --- |
| 01 Sage / Graphite | セージ `#5d7f75` | `#c9dcd6` | アクセントキー、番号、罫線、スイッチ枠 | 静かな緑の差し色 |
| 02 Cobalt / Paper | コバルト `#3f72b5` | `#c8d9ed` | アクセントキー、番号、罫線、スイッチ枠 | 青い線とキー |
| 03 Sunflower / Ink | サンフラワー `#b38a2f` | `#eadb9f` | アクセントキー、番号、罫線、スイッチ枠 | 黄色を少数キーへ点在 |
| 04 Vermilion / Lilac | 朱色 `#d9574a` | `#e7c5d3` | アクセントキー、番号、罫線、スイッチ枠、操作状態 | 本体の採用候補 |
| 05 Ultramarine / Paper | ウルトラマリン `#3157a6` | `#cdd5ee` | アクセントキー、番号、罫線、スイッチ枠 | 青を静かに配置 |

全案で背景、パネル、大半のキーキャップを白〜薄いグレーに統一する。各案の色は5個のアクセントキー、番号、共通寸法の2px罫線、スイッチ表示へ限定し、色面をページ全体へ広げない。比較案の構造・余白・番号サイズ・罫線幅は全案で共通とし、色だけを比較できるようにする。04の朱色は本体ページの押下・フォーカス・選択状態にも使う。太い蛍光マーカー風の線、グラデーション、強いグローは避ける。

## 更新後のビジュアル方針

### トーン

「入力状態とスイッチ情報を一目で確認できる、静かなツール画面」。ゲーム画面のような強いネオン表現や、意味を補わない装飾を避け、情報の階層とキーの状態を主役にする。

### カラートークン

| 用途 | 値 | 使い方 |
| --- | --- | --- |
| Base canvas | `#ffffff` | ページ全体の白い紙面 |
| Surface | `#ffffff` | 情報カード、細かな面 |
| Ink | `#252827` | 見出しと本文 |
| Muted ink | `#747a76` | 説明文、ラベル |
| Keyboard surface | `#fafaf8` | 白いキーボードを置く薄い展示面 |
| Header muted ink | `#b7b9bb` | ヘッダーなど濃色面上の補助文字 |
| Keycap | `#ffffff` | 通常キーの白いキーキャップ |
| Keycap ink | `#252827` | キーキャップ上の文字 |
| Active accent | `#d9574a` | 本体の押下・フォーカスと04案の選択表示。朱色の差し色 |
| Hairline | `#e1e2dd` | 区切り線、カードの境界 |

### タイポグラフィ

- 見出しは `Inter` 系のシステムフォントを使い、太め・詰め気味にする。ただし、大文字だけの見出しは使用しない。
- 日本語本文は `Hiragino Sans`、`Yu Gothic`、`Meiryo` の順で読みやすさを優先する。
- 英字のラベルは文頭のみ大文字など通常の大文字・小文字で記載し、全文大文字の装飾的ラベルは使用しない。キー上の表記は実機との対応を優先する。
- 本文は16px以上、行間1.7程度を基準にする。

### レイアウト

1. ヘッダー: 黒に近い細い帯に `Portfolio Lab` と `Keychron K2` だけを置く。
2. 本体ワークスペース: 上段にキーボード、下段にスイッチ情報を配置し、白基調と04の朱色で入力状態を示す。
3. 色比較セクション: 本体ワークスペースの下に5案を縦に並べ、白基調と共通の適用箇所を維持したままアクセント色だけを変更して表示する。ページ全体はこのセクションのために縦スクロールする。
4. スイッチ情報: 本体では左側のスイッチ画像と右側の押下キー、分類、製品名、荷重をまとめ、比較案でも画像、選択キー、分類、製品名、種別、荷重、表示状態の同じ情報構造を保つ。
5. 余白: 本体ワークスペースはPCとiPad横向きのviewport内に収め、色比較セクションは縦スクロールで閲覧する。

### 形状と余白

- 本体ワークスペースはviewport内の固定レイアウトとし、比較セクションは下方向へ続ける。
- ヘッダーと本体ワークスペースの左右余白は `24px〜48px`、ワークスペース内の上下2領域の間隔は `16px〜32px` を基準にする。
- `1280×800` では左右余白 `48px`、領域間隔 `32px` を使用する。`1024×768` では左右余白 `24px`、領域間隔 `16px` に縮小し、キーボードの横幅と情報カードの高さを確保する。
- 情報カードは角丸を使わないか `8px` 以下に抑え、CTAやカプセル形ボタンは使用しない。
- キーボードのキーは現行の角丸を維持しつつ、枠線の強さを抑え、キーキャップの段差を背景色の差で表現する。

### 動きと状態変化

- キー押下時は、対象キーが短く沈み込み、`Active accent` の色と小さな面の広がりで反応を示す。発光を強くしすぎず、紙面上の印として見せる。
- キーが変わったときは、スイッチ画像と詳細情報を `opacity` と `translateY` の短いトランジションで切り替える。レイアウト全体を動かさない。
- キーボード展示面には、位置を動かさず、背景の明暗だけがごくゆっくり変化する静かなモーションを許可する。`18s ease-in-out` の周期で不透明度を最大4%だけ変化させ、キー入力の視認性を優先する。
- 初期表示、ホバー/押下中、入力解除の3状態を定義する。未入力時はプレースホルダーと `未入力` / `未設定` を表示する。
- `@media (prefers-reduced-motion: reduce)` では、背景の明暗モーションとトランジションを停止し、色と表示内容の変化だけを残す。
- 動きのための追加ボタンや設定UIは置かない。ヘッダーに残すのは `Portfolio Lab` と `Keychron K2` のみとする。

## ページの実装範囲

`keychronk2.html` では、以下を確認できるようにする。

- `Portfolio Lab` と `Keychron K2` だけのヘッダー。
- 本体ページの上段キーボード・下段スイッチ情報の2領域。ここはPCとiPad横向きのviewport内に収める。
- 本体ページ下部に縦に並ぶ5つのカラーバリエーション。同じキーボードとスイッチ情報の形式と適用箇所を保ち、白基調のままアクセント色だけを変更する。
- 代表的なキー配列と、アクティブ状態の見た目。
- スイッチ画像と、キー名・分類・製品名・種別/荷重の表示。
- 装飾的な大文字ラベル、ポエム調コピー、CTA、右上ボタンを含めない構成。
- ページ全体は縦スクロールを許可するが、横スクロールは発生させない構成。
- 外部画像が取得できない場合でも、スイッチ画像のプレースホルダーを表示する。

## 非回帰条件

- Keychron K2 の6行配列を表現できること。
- 本番HTMLと同じ `16 / 15 / 15 / 14 / 14 / 10` キー構成、32分割幅、キー識別属性を維持すること。
- キーボードと背景は白基調とし、比較案ごとにアクセント色を変える。04（Vermilion / Lilac）は本体の採用候補として朱色で強調すること。
- キー押下・マウスオーバーで、対応キーを視認できること。
- スイッチ画像が取得できない場合でもプレースホルダーが表示されること。
- 本体ワークスペースはPC `1280×800` とiPad横向き `1024×768` の両方でviewport内に収まること。下部の比較セクションによる縦スクロールは許可する。
- ページ全体で横スクロールを発生させないこと。
- ヘッダーに `Portfolio Lab` と `Keychron K2` 以外のボタンやナビゲーションを置かないこと。
- 大文字だけの装飾的な見出し・ラベルと、ポエム調コピーを復活させないこと。
- スマートフォン表示は今回の非回帰対象に含めないこと。
