Trackball Controll Practiceのデザイン準拠

原本

形式
Markdown原本から生成した静的HTML

01　対象

概要

  • 課題: games/trackball-controll-practice.html の見た目が更新後の DESIGN.md に準拠していない。
  • 目的: ゲーム挙動を維持したまま、対象ページの配色、書体、形状、余白、共通ナビゲーションとフッターの表現をデザイン定義へ揃える。
  • 完了条件: 対象ページ固有の最小差分で主要なデザイン不一致を解消し、静的検証とレビューで重大な問題がないことを確認する。

02　担当

適用した役割

Portfolio UI Designer

  • 入力: DESIGN.md、対象HTML、ページ固有CSS、共有レイアウトCSS。
  • 実施内容: 旧ティール系グラデーション、多色アクセント、UI影、Avenir系書体、定義外の角丸などの不一致を整理した。
  • 成果物: 対象ページ固有クラスとCSS読込順の変更を用いた、他ページへ波及しない刷新方針。
  • 検証結果: Action Blue、白／パーチメント／黒、SF Pro系、ピル型操作、18pxカードを優先する方針を確定した。
  • 未解決事項: Controllの綴りはコピー変更となるため対象外とした。
  • 次工程への引き継ぎ: DOM構造とゲーム進行ロジックを維持し、HTMLとページ固有CSSを中心に実装する。

Portfolio Frontend Engineer

  • 入力: UI Designerの方針とプロジェクト固有の非回帰条件。
  • 実施内容: HTMLへページ固有クラスを追加し、ページCSSを共有CSSの後に読み込む構成へ変更した。ページCSSをデザイン定義準拠へ刷新し、非回帰とアクセシビリティのためFinish表示と進捗ARIAを最小修正した。
  • 成果物: 白／パーチメント／黒とAction Blue、SF Pro系、ピルボタン、18pxカード、44px黒ナビ、静的フッターを使う対象ページ。
  • 検証結果: git diff --check、JavaScript構文確認、CSS波括弧整合、JavaScriptが参照するIDの維持を確認した。Finishはviewport中央固定、補助文字はAAコントラスト、進捗方向はbreakpoint同期となるよう修正した。
  • 未解決事項: 実行環境でブラウザを利用できず、表示と操作の実動確認は未実施。
  • 次工程への引き継ぎ: ブラウザ利用可能な環境でdesktop/mobileとゲーム固有の非回帰項目を確認する。

Portfolio Performance & Accessibility Tester

  • 入力: 実装後のHTML/CSS差分、DESIGN.md、プロジェクト固有の非回帰条件。
  • 実施内容: 静的に確認可能なレスポンシブ、フォーカス、タップ領域、ゲーム状態のスタイルを確認し、Finish中央固定、補助文字コントラスト、live通知、進捗方向ARIAを指摘した。
  • 成果物: 静的検証結果と、ブラウザで確認が必要な項目の切り分け。

Portfolio Reviewer

  • 入力: origin/mainとの差分、各役割の検証結果、作業記録。

03　根拠

主要な判断

  • 判断: site-layout.cssは変更せず、対象ページへ固有クラスを追加してページCSS側で上書きする。
  • 理由: 共有レイアウトを利用する他ページへ、今回の依頼範囲外の見た目変更を波及させないため。
  • 判断: ゲームの罫線を作るグラデーションは維持し、装飾目的のグラデーションだけを撤去する。
  • 理由: Hardモードの背景移動とスクロール先までの罫線継続に必要な機能表現であるため。

  • 未解決事項: desktop/mobileの表示、キーボード操作、ゲーム固有の非回帰項目は実ブラウザで要確認。
