作業記録 006 ・ 2026-09-08

スポーツポータルのメインデザイン決定と本番反映

原本
md/work_record_006.md
状態
記録本文をHTML化

01　概要

概要

Issue #6をデザイン決定タスクとして扱い、モックアップ #6をスポーツポータルのメインデザインに採用した。決定したデザインを本番UIへ反映し、日付選択と試合カードの操作性を調整した。

02　実施内容

実施内容

  • 白〜薄いグレーのキャンバス、白い浮遊カード、ピル型ヘッダーを採用した。
  • 白・黒を基調に、マゼンタを限定的なアクセントとして使用した。
  • 表示言語を日本語に統一し、英語ラベルと不要な説明要素を削除した。
  • 日付を大きく見せず、「2026年9月6日」のような小さな表示に変更した。
  • 上部の補助情報、カード内の日付、「今日」、試合数を削除した。
  • 試合カードを1枚ずつ表示し、横スワイプで日付を切り替える構成に変更した。
  • 上部の日付チップに月・日・曜日を表示し、カードのスワイプと選択中チップを同期した。
  • 初期表示を、今日に試合があれば今日、なければ今日以降で最も近い試合日にした。
  • 勝利チームの名前とスコアをマゼンタ・太字、敗戦チームを控えめな色で表示した。
  • 更新状態と更新時刻を画面最下部へ統一した。
  • 順位表を下部シート型モーダルにした。
  • 添付されたAcctualのStyle Referenceから、白いキャンバス、近い黒の文字、薄い境界線、16px角丸、薄い影、ピル型コンテナの考え方を補助的に採用した。電気ブルーや紫、グラデーション、ゆったりした余白は採用していない。
  • デザイン決定を Issue #6 にコメントした。
  • DESIGN.md にデザイン方針と優先順位を記録した。

検証

  • npm test 成功（11件）

  • 試合カードの横スワイプと日付チップの相互同期を確認
  • 勝者・敗者の視認性表示を確認
  • 順位表下部シートの表示を確認
  • git diff --check 成功
